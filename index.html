prove-it-works Flagsmith Agent Skill

 

prove-it-works is an Agent Skill that takes Claude Code, Kiro or any coding agent through a complete Flagsmith experiment: flag, metric, traffic, verdict, rollout, cleanup. It stops and asks a human before anything touches production.

Get the skill on GitHub → MIT · one SKILL.md + six scripts · needs the Flagsmith CLI

The whole job, not one command

  1. Preflight. CLI version, login, project, environment, warehouse. One JSON line.
  2. Design. What changes, what counts as success, where in the code each lives.
  3. Create. Multivariate flag, keyed variants, metric, experiment. Not started yet.
  4. Instrument. Exposure where the user sees it, conversion where success happens.
  5. Start. Human gate. The flag locks while the experiment runs.
  6. Traffic. Real users, or scripted identities with the rates printed on the tin.
  7. Verdict. Lift, credible interval, win probability, sample-ratio check.
  8. Roll out. Human gate. Refused below 95%, on SRM, or while still collecting.
  9. Clean up. Delete the losing branch, open the PR.
  10. Archive. Only after the PR merges and no reference to the flag remains.
